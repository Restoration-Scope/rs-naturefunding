Grant workflow

How naturefunding.org finds a grant, checks it and works out what it takes an operator to apply.

1. From tip to listing

Tips come from anywhere; facts come only from the funder’s own page. Green: code, automatic. Blue: a model reads, or not built yet (marked “Next”). Amber: a person or a strong model decides. Red: left out. Purple: data in the repo.

2. Reading what it takes to apply

Code owns the workflow and every check it can state; models only read language. One programme at a time, ~30 per pull request.

3. The applicant’s view

What we structure from the pages, and how it turns into a decision for one operator. “Next” marks what isn’t built yet.
